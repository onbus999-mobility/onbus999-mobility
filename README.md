# 🚌 KCGsoft | Mobility Technology Partner

> **"KCG soft는 도시 이동의 새로운 기준을 만들어갑니다."** <br>
> 운영 가능한 서비스 구조, 현장 프로세스, 위치 데이터, 접근 권한 제어를 하나의 시스템으로 연결하는 모빌리티 기술 파트너입니다.

<br>

## 🌟 About Us
KCGsoft는 버스 회사 등 모빌리티 운영 현장에서 발생하는 흩어진 데이터(차량관제, 내부 ERP, 연료 충전, 노선 데이터 등)를 통합하여 **하나의 완벽한 운영 흐름**으로 제공합니다.

- 📊 **Insight A:** 흩어진 데이터를 모아 운행 현황을 한눈에 파악하고 현장 판단 속도를 높입니다.
- 📈 **Insight B:** 감각이 아닌, 매일 쌓이는 실제 데이터 지표를 통해 노선·배차·비용을 결정합니다.
- 🎯 **Insight C:** 증감차·정류장·수요 데이터를 기반으로 빠르고 정확한 노선 변경 결정을 지원합니다.

<br>

## 🚀 Core Services
KCGsoft는 성공적인 모빌리티 운영을 위한 핵심 솔루션 라인업을 제공합니다.

### 📍 WONDER LINX (원더 링스)
**데이터 기반 지능형 노선 설계 솔루션**
- 노선 분석, 수정, 최적 경로 도출
- 예상 운행 시간 계산을 통한 정교한 노선 설계
- `#노선분석` `#최적경로` `#운행시간`

### 🧩 통합 솔루션 라인업
- **Wonder Shuttle** : 통합 모빌리티 운영 및 탑승 흐름 관리
- **Wonder FMS** : 예약부터 정산까지 아우르는 전세버스 통합 ERP
- **Wonder Hydro** : 수소 충전소 연계 및 안정적인 충전 운영 관리
- **Catchloc** : 정밀한 GPS 위치 추적 및 실시간 차량/노선 관제 플랫폼

<br>

## ⚙️ Service Features
- **실시간 관제** : 통합 플랫폼으로 차량과 노선을 실시간 모니터링
- **데이터 리포트** : 운영 현황을 시각화하여 빠르고 정확한 의사결정 지원
- **유연한 커스터마이징** : 고객 비즈니스 환경에 맞춘 최적화된 시스템 제공
- **지속적인 운영 지원** : 전문 컨설팅 및 기술 지원
